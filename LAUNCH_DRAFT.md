## LinkedIn

I built a small open-source MCP server for LinkDing, the self-hosted bookmark
manager.

It lets compatible AI clients search, tag, add, update, archive, and delete
bookmarks without teaching each client the LinkDing API. Writes are off by
default, credentials stay local, and the offline test suite covers all ten MCP
tools.

If you use LinkDing and MCP, I would value your feedback:
https://github.com/jon-the-dev/linkding-mcp-server
